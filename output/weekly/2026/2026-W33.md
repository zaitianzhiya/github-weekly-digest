### [cloudflare/computer](https://github.com/cloudflare/computer)
`TypeScript` · ⭐ +6775

**一句话：** Cloudflare 出品的虚拟电脑环境，让 AI Agent 能在一个隔离沙盒里执行代码和访问文件，就像用一台真实电脑一样。

- **提供虚拟文件系统和运行时环境** → 给 AI Agent 提供一个安全、隔离的“电脑”环境，让它们能执行复杂任务，不用担心影响宿主系统。
- **支持多种执行后端** → 可以选择在容器里跑完整的 Linux 环境，或者在轻量级 Worker 里跑 Bash 脚本或 JavaScript，灵活适应不同任务需求。
- **状态持久化** → 基于 SQLite 存储文件系统状态，确保 Agent 即使重启也能恢复工作，保持任务连续性。
- **为 AI Agent 设计** → 允许 AI Agent 在受控环境中操作真实的文件和执行代码，是构建更强大、更自主 Agent 的基础。
