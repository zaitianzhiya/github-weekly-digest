### [cloudflare/computer](https://github.com/cloudflare/computer)
`TypeScript` · ⭐ +3599

**一句话：** Cloudflare 出品的 AI Agent 运行环境，给 AI 提供一个带文件系统和执行能力的虚拟电脑，让它能像人一样操作文件和运行代码。

- **虚拟文件系统和执行环境：** 让 AI Agent 能像操作真实电脑一样，读写文件、运行程序，而不是只在文本界面交互。
- **多种执行后端：** 支持在沙盒容器（提供完整 Linux 环境）、隔离的 Bash Shell 或 JavaScript 环境中运行 AI 的指令，满足不同复杂度的任务需求。
- **状态持久化：** 利用 Cloudflare Durable Object 和 SQLite 存储 Agent 的操作状态，确保长时间运行的任务能稳定、可恢复。
- **为 AI Agent 设计：** 旨在解决 AI Agent 在复杂任务中需要持续交互和执行外部工具的问题，让 Agent 更有“手脚”。
